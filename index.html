About Me.

Olá! Meu nome é Gustavo e sou um desenvolvedor web em formação, interessado em programação, tecnologia e criação de projetos.

Tenho conhecimentos em HTML, CSS e JavaScript, utilizando essas tecnologias para desenvolver interfaces, páginas interativas e projetos próprios. Gosto de aprender colocando o conhecimento em prática e transformando ideias em projetos funcionais.

Atualmente, venho desenvolvendo projetos que envolvem formulários, validação de dados, interfaces interativas, animações, layouts responsivos e funcionalidades em JavaScript.

Também tenho interesse em áreas como desenvolvimento web, tecnologia, programação e desenvolvimento de jogos, buscando constantemente aprender novas ferramentas e aprimorar minhas habilidades.

Este portfólio reúne alguns dos projetos que desenvolvi durante meu aprendizado, mostrando minha evolução e minha forma de aplicar programação na prática.

HTML

Estrutura e organização de páginas web.

CSS

Estilização, layouts, cores, gradientes e animações.

JavaScript

Interatividade, eventos, arrays e funcionalidades.

Projects

Register

Um formulário de cadastro feito com HTML, CSS e JavaScript. Possui validação de e-mail e senha, confirmação de senha, seleção de data de nascimento e opção para mostrar a senha. O projeto também conta com um tema escuro, animações de estrelas e elementos interativos.

Calculater

Uma calculadora feita com HTML, CSS e JavaScript, que vai além das operações básicas. Ela possui funções como fatorial, logaritmos, trigonometria, combinação, função phi e soma de divisores. Também conta com configurações de tema claro e escuro e personalização do plano de fundo.

Web Site

Um protótipo de loja virtual criado com HTML, CSS e JavaScript. O projeto apresenta produtos tecnológicos e serviços de desenvolvimento digital, com navegação entre seções, cards interativos, animações e design responsivo, voltado para programação, tecnologia e gaming.
